# strspc-pr-review-testbed-norules

E2E testbed for [SteerSpec/strspc-pr-review](https://github.com/SteerSpec/strspc-pr-review),
**without** the automatic Copilot code review ruleset. Copilot reviews here only when the action
requests it (`request-copilot-review: 'true'`). Its sibling `strspc-pr-review-testbed` keeps the
ruleset. Throwaway PRs, auto-cleaned.
